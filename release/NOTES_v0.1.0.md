# S2 Clear HUD 0.1.0 — Transparent HUD Backgrounds for 2.0.5

Initial independent release for S.T.A.L.K.E.R. 2: Heart of Chornobyl 2.0.5.

- 33 generated replacement textures remove HUD, notification and selection-wheel backgrounds.
- A new slim amber marker indicates the active additional slot.
- Current UE 5.5 package format; no gameplay configuration changes.
- No other HUD mod or S2Tweaker installation is required.

**Install:** remove an older HUD-background mod, then put all three `zzz_S2ClearHUD_P` files into `Stalker2\Content\Paks\~mods`.

**Validation:** container integrity, target paths, exact export read-back, transparent pixels and the generated marker were checked. **Not play-tested:** in-game startup and rendering remain unconfirmed.

Free, unofficial fan content for the original game. Game rights remain with GSC Game World. Build instructions, ownership information and code are included in the source repository.
