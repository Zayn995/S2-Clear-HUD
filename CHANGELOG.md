# Changelog

## 0.1.0

- Initial independent implementation for S.T.A.L.K.E.R. 2 version 2.0.5.
- 33 generated HUD texture replacements using current UE 5.5 package metadata.

- Reproducible build from a local game installation; no third-party mod input.
- Container, read-back export and pixel checks completed. In-game testing pending.
