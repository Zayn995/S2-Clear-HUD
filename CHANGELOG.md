# Changelog

## 0.1.1

- The ammo panel becomes a faint generated plate instead of being removed, so the
  game's dark ammo count stays readable against a dark scene. Reported by Molkerr
  in [S2Tweaker #9](https://github.com/Zayn995/S2Tweaker/issues/9#issuecomment-5734833722).
- New `--plate TEXTURE=R,G,B,A` build option to compare plate colours, with
  `0,0,0,0` removing a background as before.
- Uniform payloads are generated for uncompressed and BC7 textures and verified by
  decoding them back. DXT1 targets cannot carry a translucent plate and say so.
- Read-back now compares every texture's pixels against the exact generated bytes.
- Payload checks run without a game installation: `python tests/test_pixels.py`.
- The 31 removed backgrounds and the amber selection marker are byte-for-byte
  unchanged from 0.1.0. In-game appearance of the new plate is unconfirmed.

## 0.1.0

- Initial independent implementation for S.T.A.L.K.E.R. 2 version 2.0.5.
- 33 generated HUD texture replacements using current UE 5.5 package metadata.
- Clear health/stats, ammo, quickslot, interaction, attachment, notification and selection-wheel backgrounds.
- New procedural amber marker for the active additional slot.
- Reproducible build from a local game installation; no third-party mod input.
- Container, read-back export and pixel checks completed. In-game testing pending.
