# S2 Clear HUD

A free, unofficial HUD texture mod for **S.T.A.L.K.E.R. 2: Heart of Chornobyl 2.0.5**.

Removes background panels while keeping the HUD's icons, text and a slim amber marker for the active additional slot. All replacement pixels are generated by this project's code. No other mod is required.

## Coverage

- Health/stats, ammo and quickslot backgrounds.
- Interaction and attachment-prompt backgrounds.
- Quest and save-notification backgrounds.
- Selection-wheel sectors and center backgrounds.
- Ammo-type background circles in the HUD and selection wheel.

The mod replaces 33 texture packages. It does not change configuration files or gameplay settings. It is separate from S2Tweaker.

## Installation

1. Close the game.
2. Remove an older HUD-background mod if installed. In particular, remove all three `z_RemoveAllHUDBG_P` files before switching to this mod.
3. Extract the release ZIP and copy these files into `Stalker2\Content\Paks\~mods\`:

   ```text
   zzz_S2ClearHUD_P.pak
   zzz_S2ClearHUD_P.utoc
   zzz_S2ClearHUD_P.ucas
   ```

Keep the three matching files together. To uninstall, remove those same three files.

## Compatibility

Built against **game 2.0.5 / UE 5.5**. Other mods that replace the same HUD textures can conflict.

**Not play-tested.** Container integrity, asset paths, exact export read-back, transparent pixels and the generated selection indicator have been checked. In-game startup, rendering and complete visual coverage remain unconfirmed.

## Build from source

Requirements:

- Windows, Python 3.10 or newer, and `pip install -r requirements-build.txt`.
- [retoc v0.1.5](https://github.com/trumank/retoc/releases/tag/v0.1.5), downloaded separately.
- Your own installed S.T.A.L.K.E.R. 2 version 2.0.5.

```powershell
python build.py --retoc "C:\Tools\retoc.exe" --game-paks "C:\Games\STALKER2\Stalker2\Content\Paks" --output "build-local"
```

The builder reads current texture metadata and writes new pixel payloads: clear backgrounds and a procedurally drawn amber selection marker. It creates and verifies the mod ZIP without installing it or starting the game. Temporary files remain under the selected local output directory. Builds stop if expected texture structures change.

The source repository contains no game assets, extracted textures, third-party mod data, executables or Oodle DLLs. See [credits and ownership](CREDITS.md) and the [changelog](CHANGELOG.md).
